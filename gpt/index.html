About

GPT, also known as GPTPM, is the package manager used by GPTOS. It manages packages in the .gptp format and provides the package commands available inside the system.

Usage

gpt install <package>
gpt list
gpt install -f <package.gptp>

Use -f when installing a local .gptp package file.
