About GPTOS

GPTOS is a Linux-based experimental operating system developed with ChatGPT by OpenAI on the Free plan.

The project covers the OS itself, its userspace, build system, initramfs, package manager, packages, and supporting tools. The goal is to build a real, usable software project with ChatGPT rather than simply use AI to generate an isolated example.

GPTOS is currently pre-alpha and intended for testing and experimentation.

Installation

The easiest way to try GPTOS is with the pre-built x86_64 ISO.

qemu-system-x86_64 -cdrom gptos-x.x.x-x86_64.iso -m 2048 -boot d

GPT Package Manager

gpt is the package manager used by GPTOS. Packages use the .gptp format.

gpt install <package>
gpt list
gpt install -f <package.gptp>
