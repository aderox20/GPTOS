About

GPTOS is a minimal Linux-based operating system built from scratch completely by the FREE TIER of the LLM ChatGPT by OpenAI. The idea is to build a real operating system with ChatGPT rather than simply use AI for an isolated example.

Most features are still not present in the ISO because GPTOS is in pre-alpha/alpha development.

Do not use GPTOS on real hardware. It is experimental.

Features

  • Minimal Linux kernel
  • GNU utilities such as Coreutils and Binutils
  • Vibe coded package management via gpt
  • QEMU and x86_64 support
  • Custom init and initramfs setup for lightweight boot

GPT Package Manager

Current status

GPTOS is live as an experimental project. The build script currently does not work and only targets the old v0.1-prealpha state, so there is no installation process provided here for now.

The repository contains the source, documentation, and the current project files.
