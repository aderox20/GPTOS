GPTOS

A small Linux-based operating system and package ecosystem.

Source code Installation

About

GPTOS is an experimental operating system built around a minimal Linux userspace, a custom initramfs setup, and GPTPM.

It is currently in pre-alpha development and is intended for testing and experimentation rather than production hardware.

Installation

The easiest way to try GPTOS is with the pre-built x86_64 ISO.

qemu-system-x86_64 -cdrom gptos-x.x.x-x86_64.iso -m 2048 -boot d

Download and build instructions →

GPT Package Manager

gpt is the package manager used by GPTOS. Packages use the .gptp format.

gpt install <package>
gpt list
gpt install -f <package.gptp>
